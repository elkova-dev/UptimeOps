# UptimeOps - запуск на Windows

1. Установи Python 3.11 или новее. Python 3.13 подходит.
2. Распакуй ZIP. **Не запускай программу внутри ZIP**, сначала извлеки все файлы.
3. Дважды нажми `RUN_ME_WINDOWS.bat`.
4. При первом запуске создастся `.venv` и установятся зависимости. Окно консоли оставь открытым.
5. Открой `http://127.0.0.1:8002` в браузере.
6. Нажми **Monitor this app**. Программа проверит собственное API и JSON `status = ok`.
7. Выбери **Theme**, чтобы переключить палитру.
8. Нажми **Add monitor**, введи название и URL. Для API включи **API Contract Watch**, например путь `status`, условие `Equals`, значение `ok`.
9. В таблице нажми на значок часов, чтобы открыть историю, на карандаш для редактирования или на значок обновления для проверки.
10. Нажми CSV в блоке истории, чтобы экспортировать результаты.

## Проверка тестов

После установки зависимостей дважды нажми `RUN_TESTS_WINDOWS.bat`. Ожидается сообщение о пройденных тестах. Также можно выполнить из терминала папки проекта:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## Проблемы при запуске

- **Окно быстро закрывается:** открой PowerShell в папке проекта и введи `.\RUN_ME_WINDOWS.bat`.
- **Python не найден:** проверь `py --version`.
- **Port already in use:** другая программа уже занимает порт 8002. Закрой предыдущий экземпляр UptimeOps.
- **Нет данных после запуска:** нажми **Monitor this app** или добавь свой endpoint.
- **Нет доступа к внешнему API:** проверь интернет, DNS и что домен разрешается в публичный IP-адрес. По соображениям безопасности адреса локальных сетей запрещены, кроме демонстрационного endpoint.

Приложение создано для локальной работы. **Не делай его публично доступным в Интернете.**
